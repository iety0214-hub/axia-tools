## §3 手続の向き（許可／届出、事前／事後）

| 場面 | 向き |
|---|---|
| 国土法 注視区域・監視区域 | **事前**届出（契約締結前）。届出後6週間は契約締結不可 |
| 国土法 規制区域 | **許可**制（届出ではない） |
| 国土法 上記以外 | **事後**届出（契約締結日から2週間以内） |
| 勧告の対象（注視区域） | 予定対価の額 **および** 利用目的 |
| 勧告の対象（事後届出） | 利用目的のみ（対価の額は対象外） |
| 市街化区域内農地の転用 | **届出**（許可不要） |
| 市街化区域外の農地転用 | **許可** |
| 盛土規制法 規制区域内の工事 | **許可**（着手前） |
| 盛土規制法 指定時に工事中 | **届出**（指定日から21日以内） |
| 造成宅地防災区域 | 新規工事の許可制は**なし**。既存宅地への勧告（46条2項）・改善命令（47条1項） |
| 宅地造成等工事規制区域 | 保全努力義務22条1項／勧告22条2項／改善命令23条1項 |
| 建築確認 | 着工**前** |
| 開発行為の工事完了 | 完了届 → 検査 → 検査済証 → **公告** の順 |

## §5 出題形式そのものの点検（check スキル §5 で参照）

1. **個数問題**：`marks` の○の数と、正解肢が示す個数（一つ／二つ／三つ／四つ）が一致しているか数え直す。
2. **組合せ問題**：記述a〜dのうち成立するものの本数と、正解の組合せが一致しているか。
3. **問い方と正解の向き**：「誤っているものはどれか」で正解肢を○にしていないか。
4. **二重否定**：「〜が適用されないことはない」等、正誤判定できない文になっていないか。
5. **主語の省略**：「知事は」なのか「都道府県は」なのか。§2の主体と一致しているか。
   主体をずらした肢は、文字どおり読むと正解になってしまうことがある（曖昧肢）。
6. **「常に」「一切」「いかなる場合も」**：言い切りを×根拠にしている場合、
   本当に例外がないか（＝実は肢が正しくなっていないか）を条文で確認する。
